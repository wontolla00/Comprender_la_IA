Por qué existe esta Fase 0

Tu manual Comprender la IA v108 empieza en el Cap. 0 asumiendo que sabes: qué es una lista mutable vs tupla inmutable, cómo funciona una variable como etiqueta en memoria, qué es un diccionario como tabla hash y cómo modularizar código.

El repo IA-Teoria-Practica es exactamente eso: el Módulo 00 Fundamentos y Herramientas. Sin él, los alumnos se atascan en el Cap. 0.1.4 (Transformer) no por el Transformer, sino por no entender ARGS_Y_KWARGS o DECORADORES.

💡 Principio: Esta Fase 0 no es para aprender IA. Es para no tropezar con Python cuando aprendas IA. Si ya programas en Python a diario, sáltate al Cap. 0 del manual.

Para quién y qué no es

  • Es para: perfiles de datos, gobernanza, producto o QA que no han tocado Python en 6+ meses, o juniors.
  • No es para: ingenieros con Python diario. Ellos van directo a Cap. 0 — Cómo funciona un LLM.
  • No cubre: RAG, embeddings, agentes, evaluación, AI Act. Eso empieza en tu manual a partir de Cap. 1.

Cómo usar este onboarding — 3 reglas

  1. Ejecuta todo en Colab. Cada recurso tiene badge "Open in Colab". No instales nada local hasta Día 5.
  2. 45 min de foco + 15 min de juego. Los juegos (Piedra Papel Tijera, Caverna de Decisiones, Casino Aleatorio) no son extra: son donde se fija el condicional.
  3. Criterio de salida: si puedes explicar por qué lista.append() muta y tupla + tupla crea nuevo objeto, y puedes modularizar Titanic en 3 archivos, estás listo.

Día 1-2: Python esencial, condicionales y bucles

Objetivo

Recuperar sintaxis y lógica de control. Sin esto, no entiendes ni el sampling de temperatura (Cap. 0.3).

Recursos del repo (en orden)

  • INTRODUCCION_A_PYTHON_.ipynb — tipos primarios, operaciones, sintaxis básica.
  • Inteligencia_Artificial_Condicionales_.ipynb — if/elif/else, lógica booleana.
  • Bucles_Clausula_for_.ipynb — for, while, comprensión.

Labs interactivos (obligatorios)

  • Juego: Piedra, Papel o Tijera — Abrir página interactiva — ves el código JS ejecutado por ronda. Ideal para debuggear condicionales.
  • Juego: La Caverna de las Decisiones — Abrir aventura — condicionales anidadas + estado (inventario, salud).

Aquí está el 80% de bugs de novatos en pipelines RAG. Si no distingues mutable/inmutable, romperás el cache de embeddings.
